Decision cards — 3 agentic governance UCs

UC-I-017 · P0

Agent registration & ownership

Every autonomous agent is a governed object with a named human owner, declared purpose and scoped tool entitlements before it can act on systems.

GAP
drivers: OWASP-LLM06 · NIST AC-2 · CPS234-§14
UC-I-018 · P0

Agent entitlement certification / continuous attestation

Agent tool-scopes are recertified; because permissions change dynamically, point-in-time recert is replaced by continuous attestation as the good end-state.

PARTIAL
drivers: OWASP-LLM06 · NIST AC-6 · ISM-1404
UC-I-019 · P1

Agent deprovisioning / orphan-agent detection

Decommissioned or owner-less agents (and their standing consent grants) are detected and revoked — the agentic analogue of the dormant/orphan finding.

GAP
drivers: OWASP-LLM06 · NIST AC-2 · CPS234-§21
