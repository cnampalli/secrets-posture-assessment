# Sub-Agent Invocation Log

Every sub-agent run gets one row. Columns:

- **When** — ISO timestamp (AEST) of dispatch.
- **Agent #** — number from `prompts/` (00–08) or ad-hoc.
- **Prompt path** — versioned prompt file dispatched.
- **Subagent type** — `general-purpose`, `Explore`, etc.
- **Model** — model the sub-agent ran with.
- **Inputs** — what the sub-agent was given.
- **Outputs** — what files the sub-agent wrote.
- **Notes** — one-line summary of what happened. Mark `OK`, `RETRY`, `FAILED`, or `PARTIAL`.
