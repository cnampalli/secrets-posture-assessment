### 2026-05-24 (pm) — Stakeholder report + Fortanix demoted to dependency

- **Fortanix DSM demoted from the ranked set** (19 → **18 ranked vendors**)
  on stakeholder challenge. Scoring an HSM on a secrets rubric is a
  category error; a crypto substrate is *paired with* a vault, not
  *shortlisted against* one. It is **not deleted** — surfaced as a Layer-0
  crypto-substrate **dependency callout** (PRD §9.x, `matrix.md` §1.x,
  Appendix B §B.6) tied to XYZ's SafeNet→Fortanix migration, and excluded
  from rankings / cards / dashboard / viewer. CSV retains its 84 rows as
  reference. Decision: [ADR-007](PRD/adrs/ADR-007-reading-model-and-confidence.md) §A.1.
- **Interactive stakeholder report** (`matrix/matrix-viewer.html`, rebuilt
  from `build_matrix_viewer.py`): a single self-contained offline file with
  four views — (1) **XYZ posture dashboard** (0 MET / 16 PARTIAL / 11 GAP /
  20 PENDING + clickable top-gaps), (2) **By use case** decision card
  (best-fit vendors by layer + XYZ state + recommended action), (3) **By
  identity** card, (4) **Browse all** (1,512 ranked rows, layer toggles,
  jargon tooltips). INTERNAL banner; emailable as one attachment.
- README: added a **"Sharing this with the stakeholder"** section (email
  the single HTML; PDF option for the PRD; O2 internal-only caveat).
- Validated: `node --check` + DOM-shim execution (all views render, no
  runtime errors); 18 vendors / 1,512 rows confirmed.

### 2026-05-24 (am) — Stakeholder-readiness reframing (on frozen v0.1 data)

Addresses four stakeholder concerns; reading-layer changes only — the
1,596-row CSV is **not** re-scored (see [ADR-007](PRD/adrs/ADR-007-reading-model-and-confidence.md)).

- **Three-layer stack model (category fix).** Reframed PRD §9 and
  `matrix/matrix.md` §0/§1 so vendors are ranked **within** their stack
  layer, not in one flat league table — L0 crypto substrate (Fortanix),
  L1 secrets management (the vault tier + a distinct PKI/MIM lane), L2 NHI
  discovery/governance. A discovery tool's `NATIVE` (discovers) is no
  longer conflated with a vault's `NATIVE` (brokers secrets); Fortanix is
  presented as substrate, not "rank 19". Per-tier layer banners added to
  Appendix B.
- **Sourcing & confidence pass (no new research).** New PRD §8.1: honest
  posture (capability existence = vendor-doc-cited; maturity = analyst
  judgment, not independently verified; rankings = synthesis), a 4-value
  source-type taxonomy, a forward-dated-claims register (Aembit / Oasis /
  Fortanix / Doppler), and per-layer confidence summary.
- **Interactive viewer extended.** `matrix/build_matrix_viewer.py` now
  emits layer toggles (L0/L1/L2), jargon tooltips (hover any NHI / UC /
  coverage / maturity code — 94 glossary terms sourced from the catalog
  CSVs), and a "how to read this" stack-model panel. Regenerated
  `matrix-viewer.html` (1,596 rows preserved).
- **ADR-007** added; ADR-006 + README reading-paths updated.
